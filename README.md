TogCode is a cutting-edge real-time collaborative development platform that empowers engineers to synchronously manage code snippets, collaborate in shared environments, and leverage state-of-the-art AI for architectural and technical guidance. Built for high-performance teams, it brings together real-time sync, elite AI context, and a premium glassmorphic interface.

[**✨ Visit Live Demo on Render**](https://togcode-ai-frontend.onrender.com)

## 🛠 Tech Stack

TogCode leverages a modern, distributed architecture to provide sub-millisecond sync and elite technical insights.

### Frontend
- **React.js (v19)**: Atomic components with reactive state management.
- **Firebase Real-time DB**: Low-latency presence and message synchronization.
- **Vanilla CSS3**: Custom design system featuring **Glassmorphism**, vibrant gradients, and premium micro-animations.

### Backend
- **Node.js + Express**: High-efficiency AI proxy layer with tiered request management.
- **Cerebras Intelligence**: Powering TogCode AI with **Llama 3.1 70B** for senior-level engineering advice.

### Infrastructure
- **Render Cloud**: Managed deployment for both static frontend and backend services.
- **CI/CD**: Automated deployment pipeline integrated with GitHub.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher)
- Firebase Account
- Cerebras API Key

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/03musab/togcode.git
   cd togcode
   ```

2. **Setup Backend**
   ```bash
   cd server
   npm install
   # Create a .env file with CEREBRAS_API_KEY
   npm start
   ```

3. **Setup Frontend**
   ```bash
   cd ..
   npm install
   # Create a .env file with FIREBASE config & REACT_APP_API_URL
   npm start
   ```
